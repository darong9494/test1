# 케셰브 시연 순서

작성 기준: 2026-10-26 현재 로컬 작업본. 실제 브라우저 시연 완료 기록이 아니라, 확인된 코드·실행 결과를 바탕으로 만든 시연 계획입니다. 앱 버전은 0.2.11이며 기능 전체 완료나 운영 인증을 뜻하지 않습니다.

## 학생 화면의 시연 안내

「보호 현황」 → 학생 「내 앱 · 기기·세션」의 「시연 순서」 패널에서 **1 내 PC 상태 → 2 연결과 기록 → 3 학생 영역 다시 조회** 순서를 읽을 수 있습니다. 번호는 순서를 나타내는 일반 목록이며 기능 이동 버튼이 아닙니다. 아래 세 시연 절과 같은 순서입니다.

패널의 「한계」에는 Windows 실제 조회·실제 SDP 연결·브라우저 시연 미확인을, 「근거」에는 실측·로컬 API 실행 기록 확인 / 실제 브라우저 캡처 미확인 / 패키지 미생성·경로 없음으로 나눠 표시합니다. 설명용 이미지의 “위험 알림”을 현재 정상 동작하는 기능으로 추가하지 않았습니다. 현재 값과 측정 시각은 시연할 때 실제 조회로 확인합니다.

이번 변경은 student/extension.mjs와 이 문서의 안내 추가뿐입니다. 외부 API·PC 조회·설정 변경·포장 명령을 새로 실행하는 기능은 없습니다. 제공 공통 화면·스타일은 수정하지 않았고, 학생 DOM의 설치형 배치·색상은 아직 검증하지 않았습니다.

## 시연 전 준비

- 기존 프로젝트와 제출물은 유지합니다. 작업 위치는 `/Users/dy/Desktop/test1/on-client`입니다.
- 현재 시연본은 이 문서를 포함한 대시보드·학생 재조회 추가 커밋입니다. 실제 40자리 해시는 커밋 결과에서 확인합니다. 포장은 하지 않았으며 과거 제출 커밋을 현재 시연본의 버전으로 표시하지 않습니다.
- 화면 틀은 관제 대시보드형입니다. 상단 카드 네 개는 네트워크·방화벽·Windows 기록·SDP이고, 아래에 상세·화면 내 조회 기록·기능 점검표·PC 실측 패널이 있습니다. 장기간 추이 그래프는 아직 없습니다.
- 포장 목표는 기본 포장 결과와 바로가기입니다. 현재 package-app 및 제공 포장 도구가 없어 패키지·설치·바로가기 시연은 하지 않습니다.
- 실측 화면과 설명용 이미지를 섞지 않습니다. 참고 이미지는 모두 예시이며 실제 동작 근거가 아닙니다.

## 실행과 첫 화면

이미 서버가 실행 중이면 중복 실행하지 말고 http://127.0.0.1:5189/ 을 새로고침합니다. 꺼져 있다면 on-client 폴더에서 터미널을 엽니다. Windows에서는 탐색기 주소 표시줄에 powershell을 입력합니다.

```text
node --version
node src/server.mjs
```

요구 버전은 package.json의 24.19.0입니다. 다른 버전이면 지원된다고 가정하지 않습니다. 현재 PC에서 실제 사용한 번들 Node는 v24.22.1로 요구 버전 검증과 구분합니다. 이 PC에서 사용한 직접 실행 명령은 아래입니다.

```sh
cd /Users/dy/Desktop/test1/on-client
env -i PATH=/usr/bin:/bin /Users/dy/.cache/codex-runtimes/codex-primary-runtime/dependencies/node/bin/node src/server.mjs
```

이 절대 경로는 이 PC의 관측 위치이며 다른 사람에게 필요한 설치 경로가 아닙니다. 시작 메시지는 `케셰브 연결 확인: http://127.0.0.1:5189`입니다. 문구만으로 SDP·AI 연결 성공을 주장하지 않습니다. 브라우저에서 「보호 현황」을 엽니다. 제공 start-alekov.ps1은 충돌 표시가 남아 있어 사용하지 않습니다.

## 핵심 기능 세 가지의 시연

### 1. 내 PC 상태 — 값·단위·측정 시각

1. 「보호 현황」의 「내 PC 상태」로 이동합니다.
2. 「내 PC 상태 다시 측정」을 누릅니다.
3. CPU의 %, 메모리·디스크의 GiB, 각 항목의 측정 시각을 읽습니다. 처음과 재측정 값이 반드시 달라야 하는 것은 아닙니다.
4. 읽지 못한 항목은 값 대신 확인 불가와 이유, 측정 시각 확인 불가가 보여야 합니다. 실패를 시연하려고 권한·설정을 바꾸지 않습니다.

말할 내용: “현재 앱 서버 PC의 실측입니다. CPU는 약 0.5초 표본 간 평균, 메모리는 전체 물리 메모리에서 운영체제의 여유 메모리를 뺀 값으로 캐시 등을 포함할 수 있습니다. 디스크는 앱 폴더가 있는 파일시스템의 사용자 사용 가능 공간입니다.”

확인 근거: 일반 사용자 프로세스의 실제 측정 및 로컬 API 확인. 실제 브라우저 배치·클릭 시연은 아직 미확인입니다. 특정 수치를 대본에 고정해서 읽지 않습니다.

### 2. 연결과 기록 — PC 조회와 SDP 분리

1. 상단 카드 네 개와 「연결과 기록」 표를 보여 줍니다.
2. 「PC 구성·SDP 상태 다시 조회」를 누릅니다.
3. 네트워크의 주소 조회 결과와 시각을 확인합니다. 주소 목록만으로 유선·무선·인터넷 연결을 단정하지 않습니다.
4. 현재 macOS에서는 Windows 방화벽·System/Application이 확인 불가 — Windows 전용으로 표시되어야 합니다. 이를 0건이나 방화벽 비활성으로 설명하지 않습니다.
5. Windows에서 확인하는 경우에만 최근 24시간의 조회 구간·프로필별 설정·경고/오류 건수를 읽습니다. 현재 실제 Windows 결과는 미확인입니다.
6. PC 조회 성공과 별개로 SDP 미연결이 유지되는지 보여 줍니다. 일부 분류만 읽혔다면 확인된 건수와 전체 건수를 구분합니다.

말할 내용: “경고·오류 건수는 침해나 공격 탐지 결과가 아닙니다. 방화벽은 읽기만 하며 관리자 권한을 요청하지 않습니다. PC 조회가 성공해도 SDP 연결 성공이 아닙니다.”

확인 근거: 실제 macOS API에서 네트워크 조회 성공·Windows 항목 WINDOWS_ONLY·SDP 미연결 확인. 일부 실패·집계·늦은 응답 처리와 예제 상태는 시험용 데이터로 별도 검증했으며 실제 Windows 조회 성공이 아닙니다. 하단 조회 기록은 이 화면의 최근 10회 메모리 기록이며 장기 추이나 보안 원본 이력이 아닙니다.

### 3. 학생 영역 다시 조회 — 대기·실패와 다음 행동

1. 「보호 현황」의 학생 「내 앱 · 기기·세션」에서 Tab으로 「다시 조회」에 포커스를 둡니다.
2. Enter 또는 Space를 누르고 「새로 읽는 중…」과 이전 값 제거를 확인합니다. 연속 조작이 중복 요청을 만들면 안 됩니다.
3. 현재 기본 미연결 환경에서는 기기·세션 실패 항목과 ENGINE_NOT_CONNECTED, 담당자에게 연결 준비를 확인하라는 다음 행동이 보여야 합니다.
4. 「보안 기록」의 학생 「내 앱 · 보안 기록」에서도 같은 방법으로 재조회합니다. 연결 없음에서 실제 기록이나 성공을 만들어 보여 주지 않습니다.
5. 필요하면 학생 「실행 안내 한 장」과 「포장 명령과 결과」 안내를 스크롤해서 읽습니다. 접기/펼치기 버튼은 없는 일반 문서 영역입니다. 포장 참고 명령을 실행하지 않습니다.

말할 내용: “학생 영역의 허용 GET만 다시 읽습니다. 알림·진단·AI 설명 대상은 별도 제공 자료이며 전체 갱신은 상단 다시 불러오기를 사용합니다. 학생 API는 디스크나 로컬 PC 추가 API를 허용하지 않습니다.”

확인 근거: 실제 허용 API의 미연결 응답을 시험 DOM에 연결해 실패·다음 행동 확인. 대기·복구·중복 차단·포커스·지연 응답은 모의 DOM/요청으로 검증했습니다. 실제 브라우저 키보드·보조기기 동작과 설치형 반영은 미확인입니다.

## 시연을 마칠 때

| 확인 | 기록할 내용 |
|---|---|
| 시연한 원문 | 해당 작업본을 커밋한 경우 실제 40자리 값. 현재 작업본 값은 미확정 |
| 환경 | OS·Node 실제 버전·실행 폴더 |
| 실제 화면 | 본인이 확인한 화면과 시각. 현재 제공된 설명용 이미지는 근거로 사용하지 않음 |
| 실패·한계 | 확인 불가의 항목·이유. 모의 성공을 실제 연결 성공으로 쓰지 않음 |
| 패키지 | 현재 미생성. 존재하지 않는 패키지 경로나 바로가기를 적지 않음 |

종료는 직접 실행한 터미널의 Ctrl+C입니다. 재실행은 같은 폴더에서 같은 명령을 사용합니다. 유료 AI·실집행·공격 시험은 시연하지 않습니다. 상세 경계와 근거는 [정리 문서](STUDENT_DELIVERY_SUMMARY.md), 실행 문제는 [학생 실행 설명서](STUDENT_RUNBOOK.md)를 봅니다.

이 대화의 측정·테스트 출력은 작업 당시 관측이며 별도 영구 원본 로그 파일이 모두 보존된 것은 아닙니다. /private/tmp 로그는 임시 파일이라 사라질 수 있습니다. 제출용 근거가 필요하면 같은 최종 커밋으로 재측정하고 비밀·개인정보를 제외한 결과를 보존해야 합니다.

실측 표시는 값·단위·항목별 시각을 함께 보여 줍니다. 응답 확인 시각과 PC 측정 시각은 다릅니다. 예제(demo) 기록에는 예제임을 표시하며, 정상 값·권한·인터넷·SDP 상태를 만들어 넣지 않습니다. 최근 24시간 Windows 건수는 보존된 기록의 분류별 수이며 침해나 공격 탐지 결과가 아닙니다.

## 같은 결과를 다시 확인하는 순서

1. 실제 작업본의 파일과 버전을 확인합니다. 현재 추가 기능이 포함되지 않은 과거 커밋과 섞지 않습니다.
2. [학생 실행 설명서](STUDENT_RUNBOOK.md)에 따라 on-client에서 Node 버전 확인 후 직접 서버를 시작합니다. 이미 실행 중이면 중복 실행하지 않습니다.
3. [시연 순서](STUDENT_DEMO_GUIDE.md)의 세 기능을 차례대로 확인합니다. PC 실측값·시각은 그때의 실제 값으로 기록합니다.
4. 연결 없음·Windows 전용·권한 부족은 그대로 기록하며 예시 값으로 덮지 않습니다. 민감한 네트워크 주소·인증값을 공개 화면 캡처나 제출 로그에 무작정 포함하지 않습니다.
5. 실측 결과·실제 화면·모의 검증·패키지 경로를 별도 근거로 남깁니다. 패키지가 없으면 미생성으로 둡니다. 원문 AI 판정은 실제 실행 증명이 아닙니다.
6. 직접 실행한 터미널에서 Ctrl+C로 종료합니다. 같은 폴더에서 같은 명령으로 다시 켜 확인합니다.

이 문서는 코드·안내와 같은 커밋에 보존합니다. 커밋·푸시 결과는 별도 작업 보고에서 확인하며 포장·유료 AI·집행·단계 제출은 실행하지 않았습니다. 제품 상태는 검증 중입니다.
